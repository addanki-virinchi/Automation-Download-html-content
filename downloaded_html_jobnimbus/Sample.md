### Lightspeed Best Practices

The information below can be used as a “Best Practices” for hotels with Lightspeed POS in place. This is to be used as a reference when configuring Lightspeed for your hotel. Please note, all Lightspeed settings in Stayntouch PMS can be accessed from Settings > Integrations > Lightspeed POS . If you have any additional questions or would like to activate this integration, please contact Customer Support .

ACCOUNT NUMBER

When configuring Lightspeed for your property, you will need to verify that the account number in place is active in Front Desk > Accounts . This account number is used to transfer non-room charge data to the PMS so that users can reference Lightspeed POS postings within the PMS. As part of the End of Day process, non-room charge checks are sent to this account each day. Each check will be listed in the account by check number along with category items and totals.

The account should always have a 0.00 balance each day. In some cases, an account may have a balance of only a few cents, which is likely due to rounding. In this event, an agent can post the difference toward a matching F&B restaurant charge code for your property.

For additional information about Lightspeed accounts, please see this article .

MAPPING

Once a property is installed, mapping from Lightspeed should be configured to include all Product Group Mappings being sent to a charge code in the PMS. This allows items charged in the POS to appear in the PMS.

Example:

POS Posting - Fish Entree

PMS Posting - Restaurant Dinner

Note: Anytime a new product group is added in the POS, the person responsible for the Lightspeed/PMS interface on property should update the mapping. This will ensure that totals per check are correct.

If there are new items that require mapping, select the charge code option, and then drag and drop Product Groups to the appropriate section.

Please note, the Default Charge Code will be used when Product Groups are not mapped. On the check in the PMS, this charge code will appear as the item that has transferred from the POS.

TIPS

All tips from the POS are sent to the charge code configured in your Stayntouch PMS Lightspeed settings. This interface will send all tip and gratuity items to the listed charge code. The interface is unable to separate multiple tips or gratuities.

LIGHTSPEED ROOM CHARGE RECEIPTS

Lightspeed will send receipts for guest room charges to the PMS. Once posted to a room, guest F&B charges will show based on the mapping configured. The posting will appear on the bill organized by date received and Lightspeed Check Number . The Lightspeed Check Number can be used as a reference within Lightspeed POS.

Charges will show as posted with tax, and if a tip or gratuity is added to the amounts, it will be reversed and reposted to include the tip amount. This is the standard process of the interface.

LIGHTSPEED NON-GUEST REVENUE

For properties that choose to receive F&B revenue and payments, Lightspeed will send the check details and include the payments that were made in the POS. This is so that revenue and payments can be tracked within the PMS. Each day, these details are sent as part of the End of Day process. Please note, this is a feature that can be turned on or off as desired.

REPORTING

The best way to view financial details for Lightspeed is from the Journal . This can be accessed from Financials > Journal > REVENUE . From here, apply a date or date range as desired.

Upon doing so, select the charge group for your property’s F&B. This will display all revenue received from your property’s F&B outlets. By selecting a charge code from the F&B dropdown, you can view detailed check information, including guest name, check number, and amount. There is a category for each charge code that receives data from Lightspeed.

### Check In A Guest: Direct Bill

To check in a guest via direct bill, first pull up a reservation from the ARRIVALS section of the Dashboard, and if routing is already in place for the guest, you'll see an orange ROUTING indicator underneath BILL & CHARGES .

If there are any actions or notes for the guest that need to be completed, you can view those under the ACTIONS and NOTES sections and mark them accordingly. Generally, you'll want to take care of actions and notes prior to checking a guest in to ensure everything has been taken care of.

At this point, you can also add a new payment method to the stay card if desired by selecting the + ADD button underneath the PAYMENT METHOD section. In this example, we'll continue to use the credit card already attached to the reservation.

If you then select the green CHECK IN button, you'll be prompted to enter guest demographics if required. This step can be skipped if the information is not required (i.e., marked with a red asterisk [*]).

On the Room Assignment screen, as you can see in this example, there are no rooms available, because the guest has likes and preferences attached to their guest card. However, if you select the filter icon on the left side of the screen, you can clear the selected filters. This will then show all available rooms, and you can make a selection. If enabled and/or applicable to the reservation, upgrades may also be available.

Now on the Registration screen, you can review the billing information by selecting the blue BILL ROUTING button at the top of the screen. Here, you can see the charges being taken care of by the company associated with the guest.

If required, you can print a registration card at this point by selecting the orange REGISTRATION CARD button.

If using on screen check-in, you can select the FULLSCREEN button to make it more legible for the guest.

Depending on your property's settings, at this point, the guest will be required to agree to Terms & Conditions and sign on the screen to proceed with check-in.

If you then click the COMPLETE CHECK-IN button, you will be required to review the credit card authorization if billing instructions are in place. You will be prompted with three options:

- INCIDENTALS ONLY: Authorize payment for incidentals only. The amount will vary based on your property's settings. You will almost always select this option.
- FULL AUTH AS PER SET RULE: Authorize all charges for this guest on the credit card, even though some of those charges are being routed to a third party. This is rarely used.
- MANUAL CC AUTH: This will let you check in the guest without authorizing the credit card. This is particularly useful if you have a group where the group master is guaranteeing all incidental charges and does not want you to authorize the individual guest's credit card upon check-in.

Upon choosing an authorization option, you will be prompted to PLEASE SWIPE NOW or USE CARD ON FILE to complete check-in. In this example, we will use the credit card on file. At this point, authorization is complete, and the guest has been checked in.

On the stay card, you'll note that the original room type is listed as Standard 1 King Bed.

### Create New Stayntouch PMS Users

When creating a new Stayntouch PMS user, you'll need to manage the user's permissions and select their Default Dashboard view. Permissions control what the user can do and/or access in Stayntouch PMS, while the Default Dashboard determines what information (guest counts, room counts, upsell activity, etc.) the user sees when they first login to Stayntouch PMS. Read below for more details.

CREATE A USER

Step 1. Navigate to Settings

- While logged into Stayntouch PMS, choose Settings > Hotel & Staff > User Setup .

Select + ADD NEW .

Step 2. Enter Details

- Enter the user’s details . All fields with a red asterisk are required: FIRST NAME LAST NAME EMAIL ( RE-TYPE EMAIL ) JOB TITLE PASSWORD ( RE-TYPE PASSWORD )
- FIRST NAME
- LAST NAME
- EMAIL ( RE-TYPE EMAIL )
- JOB TITLE
- PASSWORD ( RE-TYPE PASSWORD )

IMPORTANT: When assigning the user a password, you DO NOT need to remember/share the password with the user. The user will receive an automated email with a link to create an entirely new password.

Step 3. User Roles/Permissions

- Then, scroll down to the User Roles section.
- Drag and drop a role to the ASSIGNED ROLES section.
- We strongly recommend only assigning one user role to the assigned section (like in the example below), to avoid creating user profiles with conflicting permissions.
- Based on the role(s) you assign, the user will have certain permissions auto-enabled for them.

Note: You can configure permission in Settings > Hotel & Staff > Permissions . There are certain permissions that control if the user can access different pages in Settings .

These pages may include the following (although some settings are not used for all properties):

- Settings > Chain
- Settings > Hotel & Staff
- Settings > Zest
- Settings > Promos & Upsell
- Settings > Cards
- Settings > Rooms
- Settings > Financials
- Settings > Rates
- Settings > Reservations
- Settings > Integrations
- Settings > Station

Step 4. Default Dashboard

- Next, at the very bottom of the page you’ll see the DEFAULT DASHBOARD dropdown menu (located under User Roles ).
- In addition to controlling what your users can do in Stayntouch PMS (with the permission settings ), you can also choose to manage their Dashboard view.
- The Dashboard in Stayntouch PMS is the main screen that opens after a user logs in. It often displays details like counts for due-in guests, due-out guests, stayovers, occupancy rates, etc.
- There are three Dashboard views in Stayntouch PMS: Manager Dashboard: Default dashboard for the Hotel Admin user role. Housekeeping Dashboard: Default dashboard for the Floor & Maintenance Staff user role. Front Desk Dashboard: Default dashboard for the Front Office Staff user role.
- Manager Dashboard: Default dashboard for the Hotel Admin user role.
- Housekeeping Dashboard: Default dashboard for the Floor & Maintenance Staff user role.
- Front Desk Dashboard: Default dashboard for the Front Office Staff user role.
- To manage which dashboard will be assigned to a particular group's DEFAULT DASHBOARD (i.e., Manager , Housekeeping , or Front Desk ), navigate to Settings > Hotel & Staff > User Roles .
- Note: Regardless of which DEFAULT DASHBOARD you assign to a user, they will still have access to all the items in the Sidebar Menu .

Step 5. Save Changes

- Always make sure to SAVE CHANGES before leaving this page.

### Update Room Status to Out of Order/Out of Service

The ability to update one or multiple rooms' statuses to Out of Order or Out of Service can be performed from the Room Status page in Stayntouch PMS. Follow the instructions below to place a room in Out of Order or Out of Service status. You can learn even more about Out of Order and Out of Service rooms here .

Step 1: Navigate to Room Status Page

- To place one or multiple rooms into Out of Order (OOO) / Out of Service (OOS), navigate to the Room Status page.
- Start selecting the Housekeeping > Room Status .

Step 2: Choose a Room

- From the Room Status page, select the room number that needs to be placed into Out of Order/Out of Service from the list view.
- Or use the search box to enter the desired room number.

Optional

- Note that you can select multiple rooms at once and update the rooms' housekeeping status (clean, dirty, etc.) or service status (OOO / OOS) with the pencil icon that appears after selecting the box beside one or multiple rooms.

Step 3: Use the "Room" Tab

- Next, select the Room tab located in top-right corner of the screen.
- Select the desired service status for the room by using the drop down menu.

Step 4: Specify Date, Reason, or Add Comments

- Select the desired TO/FROM date, ROOM RETURN STATUS , REASON , or add COMMENTS (optional) as to why the room is being placed as Out of Order/Out of Service.
- If previously configured, a list of reasons will appear in the drop down menu as this example illustrates.

Step 5: Select Update

- Click the Update button located at the bottom of the screen to submit your Out of Order/Out of Service request.

Step 6. Status Updated

- When viewing the room from the Room Status page, you will notice that the " end date " (the date the user selected from the calendar when putting the room into OOO/OOS) will now display.
- The end date indicates the last day the room is anticipated to be listed as OOO/OOS in Stayntouch PMS. (In cases where there are multiple OOO/OOS dates assigned to the room, only the end date for the most current period will display.)
- When the room reaches the end date set by the user, the room will be released back into the room inventory. At this point, the system will return the room back to the status it was in before it went OOO/OOS.
- A room can be placed OOO/OOS for more than one reason on the same day. Your property will need to check for this when balancing rooms.
- If OOO/OOS reasons are configured, when a room is marked as Out or Order (OOO) or Out of Service (OOS), the OOO/OOS reason will show for the room at a glance from Housekeeping > Room Status . This is to eliminate the need for users to click into the room to view the OOO/OOS reason.

Additional Configurations

- Your property's Out of Order / Out of Service reasons are customizable .
- To configure these settings, select the Sidebar Menu > Settings > Rooms > Maintenance Reasons.

### Permissions & User Setup

To configure permissions and set up new Stayntouch PMS users, navigate to Settings > Hotel & Staff . From there, you will see dedicated sections for Permissions and User Setup .

PERMISSIONS

In Permissions , there are different groups by which you can classify users. These groups are as follows:

- FRONT OFFICE STAFF
- FLOOR & MAINTENANCE STAFF
- HOTEL ADMIN
- SERVICE PROVIDER
- EXT. SYSTEM USER
- HOTEL SUPERVISOR
- MANAGER
- ACCOUNTING STAFF
- ZEST STATION
- REVENUE MANAGER
- RESERVATION STAFF
- FLOOR & MAINTENANCE MANAGER

For each group, there are two sets of permissions: Assigned Permissions , which are those permissions that are active for users within that group, and Not Assigned Permissions , which are those permissions that are not active within that group. You can drag and drop permissions from one column to the next as desired.

Note: Permissions tagged as Settings allow users to get into the backend to edit hotel settings, so assign carefully.

USER SETUP

Within the User Setup section, you can either search and edit an existing user or create new Stayntouch PMS users for your property by selecting the +ADD NEW button. Upon doing so, you will be asked to enter information in the following fields (starred fields are mandatory). These fields can also be edited later.

- FIRST NAME*
- LAST NAME*
- DEPARTMENT
- JOB TITLE*
- PHONE
- WORKING SHIFT
- HOUSEKEEPING SECTION
- PICTURE
- EMAIL*
- RE-TYPE EMAIL*
- PASSWORD*
- RE-TYPE PASSWORD*

Within this section, you will be asked to select ASSIGNED ROLES , which will put the user into one of the user groups mentioned in the Permissions section above. Once you've assigned a role and go to select a DEFAULT DASHBOARD , the dashboard corresponding to that user group will become available for selection.

Things to Note:

- Using several roles (with conflicting definitions in the roles) for one user can lead to issues. Once your user is updated to only have one role (e.g., the Hotel Admin role), then the issues will be resolved. Therefore, please review the permissions you need for a particular user, and assign just one role to the user .
- You never want to assign the Zest Station role to a user, as this role is only intended for the Stayntouch Guest Kiosk users and will cause an error message to display when attempting to use the role.
- If you select the SAVE CHANGES button upon creating a new user, and you are not directed back to your list of users, this means something is wrong with the information you entered, and the system will tell you what was entered incorrectly. Upon correcting the error, you should be directed back to the list of users.

Once you have created a user and assigned them a role, they will receive an email to activate their account. You can also activate their account manually by selecting the Include inactive users checkbox on the main User Setup page, searching for the user's name, and then turning ON the ACTIVE toggle.

The above explains how to configure permissions and set up new users in Stayntouch PMS. For additional information, see this video or contact Customer Support .

### Restrict Post Toggle

The Restrict Pos t setting appears on the stay card and manually controls whether or not users (and connected interfaces) can post new charges to the guest’s bill . Because it is a permission-driven feature, certain users can still opt to add charges, even if the toggle is set to restrict postings (see Permissions section below). Also, once the End of Day sequence begins running, charges will post to the guest’s bill regardless of the toggle's ON/OFF setting on the stay card.

Content:

- How to Use Restrict Post
- Permissions
- Feature Notes

HOW TO USE

ON

- The toggle is ON when it is right facing and displays in red.
- An ON setting will prevent charges from being posting to the guest’s bill (either by an interface or manually with the Add a Charge button).

OFF

- The toggle is OFF when it is left facing and displays in grey/white.
- The OFF indicates that users and connected interface can post new charges the guest’s bill (either by an interface or manually with the Add a Charge button).

PERMISSIONS

- From the Settings > Hotel & Staff > Permissions , users can assign or un-assign the Allow post when restricted permission.

Assigned

- Users with this permission CAN ma nipulate the toggle icon (ON or OFF) on a per-reservation basis.
- When attempting to post a new charge, the user (as well as connected interfaces) will still receive a notification that posting charges has been disabled for this reservation; however, they can opt to pr oceed with posting if necessary.

Un-Assigned

- Users with this permission CANNOT use the toggle icon (ON or OFF) on a per-reservation basis.
- When attempting to post a new charge, the user (as well as connected interfaces) will be prohibited from adding new charges.

IMPORTANT POINTS

No Payment Method?

- If a payment method has NOT been added, the toggle icon will not appear for selection on the stay card.
- This setting is NOT tied to the balance on the account or the current authorization on the guest’s credit card. The intended outcome for this toggle is to only limit users and interfaces from posting new charges to the guest’s bill.
- Charges will be posted during the End of Day sequence, regardless of the setting on the stay card.

### Flash Parking

Flash Guest Self Parking allows an overnight guest to be granted parking access to the parking kiosks. The guest will use their hotel keys to enter and exit a gated parking facility. Front desk has the ability to enable and disable parking access anytime during the guest's stay. For guests that choose valet parking, the FlashValet mobile application will be able to search for guest information and post valet charges to the guest folio.

INTEGRATION TO STAYNTOUCH PMS

Using the Notes feature in Stayntouch PMS, hotels can enable or remove parking access by activating or deactivating a parking account in Flash. This will allow the guest to use the hotel key card to enter and exit the parking facility up until the day of departure.

- Enable/Disable Parking: Notes must include “FPPARKS” and the key word “FPTN=xxxxxxxx”

API USAGE

- post/oath/token – To generate API credentials
- get/reservations - parameters: reservations_id, last_name or room – To search for reservations
- get/reservations - parameter date_filter: updated, date: yyy-mm-dd
- post/reservations/{id}/transactions – To post transactions to guest rooms

WEBHOOK USAGE

- Create Reservation
- Edit Reservation
- Cancel Reservation
- Reinstate Reservation
- No Show Reservation
- Checked-Out
- Room Move
- Checked-In

To set up this integration, the following tasks need to be completed:

- Hotel needs to send authorization to their Stayntouch Client Success Manager (CSM) allowing Flash Parking to access their data.
- Once received, the CSM will forward data to the Implementations Team for setup. Implementations will generate an API OAuth keys. Once the keys are created, Stayntouch will send them to Flash Parking.
- Implementations will generate an API OAuth keys.
- Once the keys are created, Stayntouch will send them to Flash Parking.

2. From the OPEN BILLS screen of the A/R Transactions tab, click ADD MANUAL BALANCE .

3. Enter the following information:

- Enter a name for the balance in the NAME field.

NOTE

- The default is Manual Balance . You can choose to keep the default name or enter a more unique name.

- Enter the invoice number of the original invoice in the INVOICE NO. field.

- Enter the date that the original invoice was generated into the AGING DATE field.

- Enter the amount total of the original invoice in the amount field.

- To enter additional balances, click the green plus (+) sign.

Click SAVE .

### Automatic Check-Out at End of Day for Day Use Stays

If the guest is set to stay for 0 nights (i.e., a Day Use stay), and you run the End of Day (EOD), Stayntouch PMS will automatically check out those guests, as they are due to depart on that specific date, and you are closing that business date.

If you do not want the guest to be automatically checked out, you can either run your EOD after these guests have departed, OR you can leave them as a 1-night stay. If they arrive on one day and depart the following day, it is a 1-night stay. Stayntouch PMS does not work in "midnight to midnight" when identifying a stay as 1 night or 0. We use the Stayntouch PMS business date.
